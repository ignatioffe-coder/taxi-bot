# 🚕 Taxi Forecast Bot

Бот для таксистов Москвы. Собирает коэффициенты по районам и даёт рекомендации, где и когда выгоднее работать.

## Быстрый старт

### 1. Создай бота в Telegram
- Напиши [@BotFather](https://t.me/BotFather)
- Отправь `/newbot`
- Придумай имя и username
- **Скопируй токен** — он выглядит как `123456789:ABCdefGHIjklMNOpqrsTUVwxyz`

### 2. Установи зависимости
```bash
pip install -r requirements.txt
```

### 3. Настрой конфиг
Открой `config.py` и вставь токен:
```python
BOT_TOKEN = "123456789:ABCdefGHIjklMNOpqrsTUVwxyz"
```

Найди свой Telegram ID (напиши [@userinfobot](https://t.me/userinfobot)) и добавь в `ADMIN_IDS`:
```python
ADMIN_IDS = [123456789]  # Твой ID
```

### 4. Запусти бота
```bash
python bot.py
```

Бот начнёт работать. Отправь `/start` в Telegram.

## Как пользоваться

### Для водителя (брат):
1. Открывает бот, нажимает **«Прислать коэффициент»**
2. Выбирает район из списка
3. Вводит текущий коэффициент (например: `1.3`)
4. Указывает погоду (или пропускает)
5. Готово! Бот показывает статистику по району

### Для просмотра рекомендаций:
- **«Рекомендации сейчас»** — куда ехать прямо сейчас
- **«Моя статистика»** — сколько данных прислал
- **«Топ моменты»** — лучшие коэффициенты за всё время

## Как это работает

Бот собирает данные от водителей и строит простую статистику:
- Средний коэффициент по районам
- Лучшее время для работы
- Зависимость от погоды и дня недели

**Чем больше данных — тем точнее прогнозы.**
